**Seismic Alert**

An Android app built with Godot 4 that uses the phone's accelerometer to detect shaking. When the measured magnitude exceeds a threshold, an alarm sounds, the phone vibrates, and a button appears allowing the user to send an SMS notification to a saved contact.

It was originally developed as a school science fair project, exploring the possibility of using sensors already built into smartphones instead of relying on expensive seismographs.

«Honest disclaimer: This app does not predict earthquakes or connect to any seismic monitoring network. It detects when your phone is moving. It is intended as a local shaking alarm and a learning project, not as an early earthquake warning system.»

Project Background

This project was originally created for a science fair, with the goal of exploring an accessible, smartphone-based approach to detecting ground shaking.

The initial concept was based on the scientific distinction between P-waves and S-waves, investigating whether a smartphone's built-in MEMS accelerometer could provide useful information about seismic activity.

The project report and original research documentation are not included in this repository.

The repository focuses on the software implementation, its current limitations, and the technical work still required to make the concept more reliable.
